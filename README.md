# 📸 ¿Cómo agregar una imagen?

1. Entra a la carpeta `img`.

3. Coloca el nombre que utiliza el código.

Por ejemplo:

```text
corte.jpg
```

Después aparecerá automáticamente en el sitio.

# 📱 RESERVAS

El sitio cuenta con un sistema de reserva.

El cliente puede seleccionar:

* Nombre
* Teléfono
* Servicio
* Fecha
* Hora
* Mensaje

Después de pulsar:

```text
CONFIRMAR RESERVA POR WHATSAPP
```

# 📲 CAMBIAR NÚMERO DE WHATSAPP

Abre:

```text
js/script.js
```

Busca:

```javascript
const numeroWhatsApp = "573000000000";
```

Cambia el número por el número real de la barbería.

IMPORTANTE:

Coloca el número con:

```text
57
```

antes del número colombiano.

Ejemplo:

```javascript
const numeroWhatsApp = "573123456789";
```

No coloques:

```text
+
espacios
guiones
paréntesis
```

