# 💈 BARBER ATT THE BEST

Sitio web moderno, elegante e innovador para una barbería.

Diseñado con HTML, CSS y JavaScript.

---

## ✂️ Características

- Diseño elegante y moderno
- Diseño responsive para celulares
- Sección de inicio
- Sección de nosotros
- Servicios
- Galería de trabajos
- Formulario de contacto
- Animaciones
- Botones de reserva
- Compatible con GitHub Pages
- Fácil de personalizar
