# 💈 BARBER ATT THE BEST - Website

Sitio web moderno, elegante y adaptativo diseñado para la barbería **BARBER ATT THE BEST**. Incluye una galería interactiva de cortes y un sistema de reservas directo integrado con WhatsApp.

## 🚀 Características
* **Diseño Dark Gold Premium**: Estética limpia con paleta de colores oscuro y dorado.
* **Layout Responsive**: Totalmente optimizado para dispositivos móviles, tablets y ordenadores.
* **Sistema de Reservas**: Formulario funcional que procesa la cita y redirige a WhatsApp con los detalles estructurados.
* **Galería Optimizada**: Espacios listos para mostrar el catálogo de cortes y servicios.
